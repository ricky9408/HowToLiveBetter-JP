# 日本でよりよく暮らすためのガイド

日本で暮らす人のために、健康、お金、時間、権利を守る行動をまとめた生活ガイドです。国籍を問わず使える情報に加えて、外国籍の方向けの在留・就労・生活手続きを収録しています。本文、画面、開発文書、コメントを日本語で統一しています。

原著 [eternity4719/HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) の34章のテーマをもとに、日本の制度へ再編集した版です。原著の全項目の逐語訳ではありません。中国固有の法令、社会保険、行政窓口、金額、広告を日本向けの内容に置き換え、外国籍の方向けの第35章を追加しました。原著者の監修を受けた版ではありません。

## 読む前に

初回の制度確認日は **2026年10月13日** です。各項目に出典を付けています。制度は年度、自治体、年齢、所得、雇用・加入状況、在留資格で変わります。申請、契約、受診の前に担当機関の現行案内を確認してください。確認した範囲と、公式ページの本文を取得できなかった事項は確認記録に残しています。

緊急の救急・火災は **119**、警察への緊急通報は **110** です。消費者契約の相談は **188** で最寄りの窓口へつながります。相談の受付時間、費用、対応言語は窓口ごとに確認してください。

外国籍の方の国籍・在留資格・税務上の居住区分は別の条件です。「外国籍」を選んでも、在留や受給の資格が自動的に認められるわけではありません。観光、留学、就労、身分に基づく在留、特別永住では使える制度や必要な手続きが異なります。

このガイドは医師、弁護士、行政機関による個別の判断に代わるものではありません。法令への適合を保証する法律監査は実施していません。健康・金融・法務の判断には、該当する公式資料と資格のある専門家を使ってください。

## 項目の読み方

各項目は、**費用 → 要点 → 効果 → 根拠の区分 → 出典 → 補足** の順です。検索用のタグで必要な情報を絞れます。

| 根拠の区分 | 意味 |
| --- | --- |
| A | 原著研究などの量的な根拠がある。対象者や研究条件は項目で確認する |
| B | 公式の制度・公的指針、または限定的な研究に基づく |
| C | 計画や整理のための提案。因果関係や利益を証明したものではない |

費用と効果の「大・中・小」は検索のための編集判断です。法的な重要度や研究の効果量を同じ尺度にしたものではありません。費用の「0」も、制度そのものが無料という意味ではなく、項目で勧める行動の追加支出を指します。健康、お金、時間、権利の効果は別々に読み、個人の余命や収益に合算しません。

## 画面と保存データ

画面の「暮らし方」で、共通の情報、外国籍の方向けの情報、日本国籍の方向けの情報を選べます。外国籍の方向けの表示にも共通の健康・生活情報は含まれます。在留資格の選択は確認すべき情報を案内するためのものです。

検索、章・分野・負担・根拠の絞り込み、項目の保存、配色の切り替えを使えます。保存した項目、表示設定、生活チェックの回答はブラウザーの端末内に保存します。本アプリにはそれらを送信する処理、広告、解析用スクリプトを組み込んでいません。出典を開くと外部サイトへ移動します。端末を共有している場合は画面の保存データ削除機能を使ってください。

## 電子版の生成と配布

EPUB、PDF、オフライン単一HTML、Anki用の復習カードを同じ本文から生成します。生成物は `dist/HowToLiveBetter-JP.*` です。中国版のカードと混同しないよう、日本版専用の識別子を使います。

この変更だけではサイトやリリースは公開されません。GitHub Actions の検査・生成・配布処理が完了した後の配布先は、このリポジトリの [epub-latest リリース](https://github.com/ricky9408/HowToLiveBetter-JP/releases/tag/epub-latest) です。

## 開発と検査

Node.js 24以降を使います。本文の形式、参照、要点、統計を検査します。

```bash
node tools/sync-stats.mjs --no-screenshot
node tools/check-refs.mjs --check
node tools/check-plain.mjs
node tools/check-split.mjs
node tools/sync-stats.mjs --check
```

生成の準備は `tools/epub` の依存関係をインストールします。

```bash
npm --prefix tools/epub ci
node tools/epub/build.mjs
node tools/offline/build.mjs
node tools/anki/build.mjs
node tools/pdf/build.mjs
```

PDFは Pandoc と Typst、日本語の Noto CJK フォントが必要です。生成物の本文照合には Poppler の `pdftotext` も使います。別の場所にある場合は環境変数 `PDFTOTEXT` に実行ファイルを指定します。必要なバージョンとインストール手順は [生成ワークフロー](.github/workflows/book.yml) にあります。オフラインHTMLは生成後にそのファイルを直接開けます。

オンライン版をローカルで確認するには、リポジトリ内で `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。`index.html` の直接起動では本文の取得がブラウザーに制限されるため、サーバーまたは生成済みオフライン版を使います。

公式出典の接続検査は `node tools/check-links.mjs` で行います。404・410などの失効と、403・タイムアウトなどの取得不能を区別します。取得不能は内容の正誤を示しません。リンク検査に加え、制度の改定時は本文との一致を確認します。

生成後は `node tools/check-exports.mjs` で、EPUB、PDF、オフライン版、Ankiの本文と参照を照合します。解析処理の回帰検査は `node --test tools/test/*.test.mjs` で行います。

表紙の統計は上記の同期で更新されます。画像も更新する場合は `node tools/sync-stats.mjs` を使います。Chromeが使えない環境や自動撮影が制限される環境では、`tools/og.html` をブラウザーで表示して1200×630の画像を `og.png` として保存してください。自動撮影は30秒で停止し、本文の統計と参照の更新は先に完了します。
