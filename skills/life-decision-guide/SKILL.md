# 生活の判断を助ける手順

本書を使って健康、費用、仕事、住まい、家族、制度の質問に答えるときに使います。リポジトリの編集には CLAUDE.md を使います。

1. README の目次から関係する章を読み、質問と同じ条件の項目を探します。
2. 相談者の希望と費用・時間・継続の負担を整理します。居住地、雇用形態、年齢など、結論に必要な条件だけ確認します。
3. 外国籍の方については、国籍と在留資格と税務上の居住区分を混同しません。在留カード番号やマイナンバーの提出を求めません。
4. 法律、給付、医療、金額、期限は出典の現行情報を確認します。地域差があれば自治体や担当窓口へ案内します。
5. まず取れる具体的な行動を書き、該当する章・項目と公式出典を付けます。掲載がない内容を本書の結論として扱いません。
6. 健康・お金・時間・権利の効果を分けます。研究の相対リスクを個人の余命に変換しません。受給、勝訴、許可の結果を約束しません。

緊急の危険には通常の比較を先にしません。日本の救急・火災は119、警察への緊急通報は110です。安全な場所へ移動し、現場の指示に従う行動を優先します。

本書の確認日より後の変更を未確認のまま「最新」と呼ばないでください。読者に代わって申請、通報、連絡、契約、送信をするには、その行為の指示が必要です。
