# 日本版の方針

[← 総目次に戻る](../README.md)

## 対象と変更

日本での生活に使える情報を、日本語で読みやすくまとめます。原著の健康、お金、時間、権利というテーマを引き継ぎ、日本の法律・社会保障・行政手続きに合わせて再編集しています。外国籍の方には在留と日常生活の情報を追加しました。

中国の制度の名称だけを日本語に訳して使うことはしません。中国の行政窓口、給付計算、営業許可、通信の規制、軍や公務への進路は、日本の条件に置き換えました。金額は日本円を使います。原著の広告や寄付用の画像は日本版に掲載しません。

原著の全項目の逐語訳ではありません。日本での適用を確認できる内容に整理し直しています。中国版の法令の検証記録を日本版の確認記録として転用せず、Git の履歴に残しています。

## 判断の前提

法律上の義務、行政機関の案内、医学上の推奨、生活の計画を区別します。自治体の条例、学校や雇用主の規則、賃貸契約の条件が関係する場合もあります。契約に書いてあることがすべて有効とは限らないため、争いがあれば専門家や相談窓口を使います。

制度の対象になるかは、国籍だけでは決まりません。在留資格、居住地、年齢、収入、雇用、加入している保険を確認します。在留資格の「永住者」と、所得税法の「非永住者」「非永住者以外の居住者」の区分は対応しません。

各項目の出典と補足に適用条件を示します。初回の確認日は2026年10月13日です。すべての条文や個別事情を審査する法律監査ではありません。本文を根拠に、許可・受給・合法性の結果を保証しません。

## 情報の更新

法令は [e-Gov 法令検索](https://laws.e-gov.go.jp/)、制度は担当機関の公式ページで確認します。確認日は [制度の確認記録](制度の確認記録.md) に残します。改定予定は、施行済みの条件と分けて書きます。

接続検査はリンクの失効を探すためのものです。ページが開けても、文章が現行の制度と合っているとは限りません。本文が取得できない資料は、その制限も記録します。

## 保存と公開

画面の保存機能は端末内のブラウザー保存領域を使います。在留カード番号、マイナンバー、診療記録の入力を求めません。外部の出典を開くと、そのサイトへ接続します。

原著と日本版の表示、ライセンス、変更したことの表示を保ちます。ライセンス原文と著作権表示は変更せず、日本語の説明を添えています。
