# 夜勤と生活リズム

[← 総目次に戻る](../README.md)

夜勤の有無を選べるか、勤務の変更が可能か、収入と健康にどんな影響があるかを分けて考えます。眠気を我慢できるかだけで判断しないでください。

- 勤務、睡眠、移動、食事の時刻を記録し、休める時間を確認する。
- 帰宅後に眠れる環境を確保し、家族と生活時間を相談する。
- 強い眠気があるときは運転を避け、安全な移動方法を確保する。
- 症状が続く場合は医療機関や産業医に相談する。
- 深夜業の健康診断、労働時間、休憩、割増賃金を勤務先で確認する。

健康面は [毎日の健康を守る](../book/02-毎日の健康を守る.md)、勤務条件は [仕事・退職・労災](../book/19-仕事・退職・労災.md) を参照します。研究結果を個人の病気の予測や転職の結論に直結させず、実際の症状と勤務条件を専門家に相談してください。
