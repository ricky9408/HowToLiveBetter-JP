# 外国籍の方の生活チェックリスト

[← 総目次に戻る](../README.md)

この一覧は手続きの見落としを減らすためのものです。すべての人に同じ申請が必要とは限りません。期限や適用条件は [第35章](../book/35-日本で暮らす外国籍の方へ.md) と出入国在留管理庁の現行案内で確認してください。

## 来日前と住まいが決まった後

- 在留資格、在留期限、許可された活動を確認する。
- 住まい、保証会社、初期費用、退去条件を確認する。
- 対象者は住居地の届出を行い、住民登録の内容を確認する。
- 健康保険と年金について、勤務先と市区町村で加入先を確認する。
- 緊急連絡先、災害情報、避難場所を日本語と理解できる言語で控える。
- 銀行口座、携帯電話の契約に必要な本人確認書類を確認する。

## 仕事を始める・変える

- 実際の仕事内容が在留資格の範囲に含まれるかを確認する。
- 留学や家族滞在で働く場合は、資格外活動許可とその条件を確認する。
- 複数の仕事をしている場合は、労働時間を合計して確認する。
- 雇用契約、賃金、労働時間、社会保険を記録する。
- 所属機関の届出が必要か、変更申請が必要かを確認する。
- 海外の会社の仕事を日本から行う場合も、在留と税の条件を別々に確認する。

仕事の権利は [第19章](../book/19-仕事・退職・労災.md)、事業を始める場合は [第12章](../book/12-起業と事業運営.md) も参照してください。

## 引っ越し・出産・出国

- 住民登録、保険、年金、在留の各届出を区別して確認する。
- 日本で子どもが生まれる場合は、出生届と在留資格の手続きを分けて確認する。
- 出国前は再入国の方法、帰国期限、在留期限を確認する。
- 長期に帰国する場合は、住民税、口座、賃貸、保険の処理を確認する。
- 脱退一時金は将来の年金への影響や社会保障協定を確認してから判断する。

## 相談先

[外国人生活支援ポータルサイト](https://www.moj.go.jp/isa/support/portal/) と [生活・就労ガイドブック](https://www.moj.go.jp/isa/guidebook_all.html) に、分野ごとの公式案内があります。日本語が難しい場合は、自治体の国際交流窓口や相談窓口に対応言語・通訳の有無を確認してください。

窓口へ伝えるための質問はメモにできます。身分証番号や個人の病歴を公開の課題やコメントに書かないでください。
