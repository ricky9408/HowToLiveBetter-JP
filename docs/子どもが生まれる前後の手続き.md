# 子どもが生まれる前後の手続き

[← 総目次に戻る](../README.md)

妊娠、出産、出生後の届出は、医療機関、自治体、勤務先、保険者で提出先が異なります。妊娠中から担当窓口に確認し、家族で分担します。

## 妊娠中

- 妊娠の届出、母子健康手帳、健診の助成について自治体で確認する。
- 出産施設、移動方法、急な症状の連絡先を決める。
- 勤務先に産前産後休業や育児休業、給付と保険の扱いを確認する。
- 保育や家事を頼める人、利用できる支援、必要な費用を整理する。

[妊娠と出産の準備・手続き](../book/27-妊娠と出産の準備・手続き.md)、[育児の費用と支援](../book/18-育児の費用と支援.md) を使います。

## 生まれた後

- 出生届、子どもの健康保険、自治体の医療費助成や手当を確認する。
- 新生児の検査、予防接種、健診の予定を確認する。
- 保護者の休養と受診、育児の相談先を確保する。
- 母子健康手帳やお薬手帳を家族が使えるように保管する。

[乳児の育て方](../book/20-乳児の育て方.md) は安全な寝かせ方や受診の目安を扱います。急な異変は [緊急時の行動](../book/13-緊急時の行動.md) に従い、緊急時は119へ通報します。

## 外国籍の保護者・子ども

出生届を出しただけで国籍や在留資格が自動的に決まるとは限りません。日本で生まれた子どもの国籍、旅券、在留資格は、それぞれの担当機関に確認してください。日本の届出と、本国の大使館・領事館への届出を分けて控えます。

詳しい期限と適用条件は [第35章](../book/35-日本で暮らす外国籍の方へ.md) にあります。給付の対象は居住、所得、加入する保険などで変わるため、金額を一律に見込まないでください。
