# 交際と結婚の生活設計

[← 総目次に戻る](../README.md)

交際や結婚を勧める結論を一律に出さず、住まい、お金、仕事、家族の希望を話し合うための一覧です。法律と自治体の制度は [交際と結婚を考える](../book/10-交際と結婚を考える.md) で確認します。

| 話し合うこと | 確認する内容 |
| --- | --- |
| お金 | 収入、借入れ、生活費の分担、預金の管理 |
| 住まいと仕事 | 契約名義、通勤、転勤、介護、退職時の生活費 |
| 子ども | 希望、育児の分担、仕事と支援の利用 |
| 緊急時 | 医療の連絡先、意思の伝え方、書類の保管 |
| 別々に暮らす場合 | 住まい、支払い、連絡方法、相談先 |

相手の同意を尊重し、脅しや暴力があるときは安全を優先します。危険が迫るときは110です。暴力の相談は同居や夫婦関係の改善より先に、支援窓口につなぎます。

自治体のパートナーシップ制度、婚姻、相続、医療の代理は別の制度です。使える範囲を担当機関で確認します。国際結婚は婚姻の手続きと在留の手続きを分け、[外国籍の方の章](../book/35-日本で暮らす外国籍の方へ.md) も確認してください。
