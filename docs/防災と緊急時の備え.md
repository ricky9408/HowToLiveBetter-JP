# 防災と緊急時の備え

[← 総目次に戻る](../README.md)

地震、津波、台風、豪雨を考え、住まいの地域に合う備えをします。避難が必要なときは物を集めるより先に安全な場所へ移動してください。

## 家族で決めること

- 自宅と職場のハザードマップ、避難場所、移動経路を確認する。
- 家族と連絡が取れないときの集合場所や連絡方法を決める。
- 高齢者、乳幼児、障害のある家族、持病のある人の必要な物と移動方法を確認する。
- 警報や避難情報を受け取れるようにする。外国籍の方は理解できる言語の情報源も用意する。

## 備蓄と持ち出す物

飲料・調理用の水は1人1日おおよそ3リットル、食品は最低3日分、できれば1週間分が公的な備蓄の目安です。体格、気温、食事、治療によって必要な物は変わります。普段使う物を少し多めに置き、使った分を補充します。

| 用途 | 準備する物 |
| --- | --- |
| 水・食事 | 水、食べられる保存食、食物アレルギー対応の食品 |
| 暗さ・通信 | 懐中電灯、充電器、電池、連絡先の控え |
| 衛生 | 携帯トイレ、衛生用品、必要な育児用品 |
| 治療 | 必要な薬、お薬手帳、眼鏡、医療機器用の電源の相談 |
| 移動 | 歩ける靴、雨具、季節に合う衣類 |

持ち出す荷物は、自分で安全に運べる量にします。備蓄を買う費用と、避難の妨げになる重さを分けて考えてください。

## 緊急時

救急・火災は119、警察への緊急通報は110です。住所、目印、何が起きたかを伝え、指示に従います。津波のおそれがある場所では、強い揺れや長い揺れを感じたら高い場所へ避難します。

[命を守る](../book/01-命を守る.md) と [緊急時の行動](../book/13-緊急時の行動.md) を事前に読んでください。
