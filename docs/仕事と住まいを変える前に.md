# 仕事と住まいを変える前に

[← 総目次に戻る](../README.md)

退職、転職、引っ越しを同時にすると、保険や届出の見落としが起きやすくなります。勤務先と住居の変更を別々に整理し、提出先と期限を控えます。

## 退職前

- 労働条件、未払い賃金、残業、休暇の記録を保管する。
- 退職理由に納得できない場合は、書類に署名する前に相談する。
- 離職票や源泉徴収票など、必要な書類の発行時期を確認する。
- 次の健康保険と年金の扱いを確認する。勤務先の保険がそのまま続くと考えない。
- 失業給付や就職支援の要件をハローワークで確認する。

[仕事・退職・労災](../book/19-仕事・退職・労災.md) と [生活費に困ったとき](../book/07-生活費に困ったとき.md) が詳しい説明です。

## 引っ越し前後

- 賃貸契約の解約通知、退去費用、入居時の写真を確認する。
- 新居の家賃だけでなく、初期費用、通勤費、更新条件を比較する。
- 住民登録、保険、年金、税、学校、銀行、公共料金の手続きを控える。
- 防災情報と避難場所を新しい住所で確認し直す。

契約は [賃貸と住宅購入](../book/15-賃貸と住宅購入.md) を参照してください。

## 外国籍の方

住民登録の住所変更と、入管への所属機関の届出は別の手続きです。転職後の仕事内容が在留資格の範囲に合うかも確認します。[外国籍の方の生活チェックリスト](外国籍の方の生活チェックリスト.md) と [第35章](../book/35-日本で暮らす外国籍の方へ.md) を使ってください。

この一覧は提出義務を確定するものではありません。書類、期限、給付は各章の出典と担当窓口で確認します。
