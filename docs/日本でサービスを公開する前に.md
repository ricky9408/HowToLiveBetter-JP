# 日本でサービスを公開する前に

[← 総目次に戻る](../README.md)

日本ではサイトを作るだけで中国のICP届出が必要になるわけではありません。一方、扱うサービス、個人情報、決済、販売、広告によって日本の法律が関係します。まず何を提供するかを書き出してください。

| 確認すること | 本文の参照先 |
| --- | --- |
| 事業の届出、税、業種別許可 | [起業と事業運営](../book/12-起業と事業運営.md) |
| 通販の表示、個人情報、決済、削除相談 | [ウェブサイトやサービスの運営](../book/26-日本でウェブサイトやサービスを運営する.md) |
| 素材の権利、ソフトウェアの許諾、許可のない試験 | [技術の仕事と法律](../book/11-技術の仕事と法律.md) |
| 外国籍の方が事業をする際の在留 | [外国籍の方の章](../book/35-日本で暮らす外国籍の方へ.md) |

公開前に、運営者、問い合わせ先、利用条件、必要な法定表示を確認します。収集する情報を必要な範囲に絞り、利用目的、保管、アクセス権、削除の対応を設計します。

自分のサービスでお金を預かること、代金を集めて他人へ移すこと、投資や医療の助言を売ることは、それぞれ業規制の確認が必要です。「小規模」「無料」「国外サーバー」という理由だけで対象外と決めないでください。

この一覧は事業ごとの法的な審査を代行しません。該当章の担当機関と、必要に応じて専門家へ確認します。
