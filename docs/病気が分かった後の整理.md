# 病気が分かった後の整理

[← 総目次に戻る](../README.md)

診断の直後にすべてを決めようとせず、次の受診までに必要な情報を整理します。治療の中断や薬の変更は自分だけで決めず、主治医・薬剤師に相談してください。

- 病名、検査結果、治療の目的、次の受診日を控える。
- 服用中の薬、市販薬、サプリメントをお薬手帳などにまとめる。
- 急いで連絡すべき症状と、夜間の連絡先を医療機関で確認する。
- 治療費、保険で対象になる範囲、高額療養費などを保険者に確認する。
- 仕事や家事が難しい場合は医療機関の相談員と勤務先へ相談する。
- 希望する場合は家族や支援者に、手伝ってほしいことを伝える。

治療を続ける工夫は [慢性疾患と付き合う](../book/16-慢性疾患と付き合う.md)、受診と保険は [日本で医療を受ける](../book/24-日本で医療を受ける.md)、家庭の薬は [家庭の薬を安全に使う](../book/34-家庭の薬を安全に使う.md) を参照します。

外国籍の方は保険の加入先と資格確認の書類を確認し、必要なら通訳の利用を医療機関に相談してください。在留資格と医療保険の資格は別々に確認します。急な重い症状は書類の整理より受診を優先します。
