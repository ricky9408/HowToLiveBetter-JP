# 目の前で人が倒れたとき

[← 総目次に戻る](../README.md)

まず車、火、電気、水など周囲の危険を確認します。安全に近づけない場所へ無理に入らず、119へ場所と状況を伝えます。

安全に近づける場合は、反応と普段どおりの呼吸を確認します。反応がなく普段どおりの呼吸がない、または判断できない場合は、119に連絡し、電話の指示に従って胸骨圧迫とAEDを使います。近くの人に通報やAEDの手配を頼めます。

詳細は [緊急時の行動](../book/13-緊急時の行動.md) で確認し、消防や日本赤十字社の講習で練習してください。乳児・子ども、溺水、けがなどで対応が異なります。本書だけで訓練を受けたことにはなりません。

救助をしたらあらゆる責任が免除される、または必ず責任を問われる、という一律の結論は書きません。具体的な状況と日本の法令を確認します。危険な撮影や公開より、通報と安全な救助を優先してください。

出典：[消防庁の救急お役立ち情報](https://www.fdma.go.jp/mission/enrichment/appropriate/)、[日本赤十字社の講習](https://www.jrc.or.jp/study/)。初回確認日：2026年10月13日。
